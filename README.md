# 🂠 卡牌对决

基于你原创规则《我的卡牌》的**浏览器联机卡牌对战游戏**——五阵营、建筑攻防、状态效果系统,支持 **1v1 / 2v2 / 1v1v1 多房间同时在线**。

## 快速开始

1. **双击 `start.bat`**(或命令行 `npm start`)
2. 浏览器自动打开 `http://localhost:8080`
3. 输入昵称 → 选择阵营 → 创建房间(或加入别人的房间)

> 同一个 Wi-Fi 下的朋友访问 `http://你的局域网IP:8080` 即可联机(启动时会显示IP)。

## 📋 卡牌详情与目标高光

- 手牌区上方固定信息面板:点击卡牌/建筑/状态效果,其详细描述显示在面板中(点击✕或点击其他内容切换)
- 选定攻击目标建筑时,目标周围显示金色高亮光圈(边框+外发光+放大)

## 🎨 UI 风格

- 米白纸面浅色主题,全站浅色化,卡片带纸张质感阴影
- 阵营主题色:主世界🟢绿 / 地狱🔴红 / 终界🔵蓝 / 虫族🟤棕 / 创世神🟡金(对应区块背景色)

## 📱 手机端适配

手机/平板直接访问(手机和电脑在同一 Wi-Fi 时访问局域网地址,跨网络时访问公网地址即可),界面会自动切换为竖屏触屏布局:手牌横向滑动、建筑区紧凑化、按钮加大。

## 🌐 跨网络联机(不在同一 Wi-Fi)

**双击 `联机上网.bat`** 即可:
1. 自动启动游戏服务器
2. 自动建立 Cloudflare 免费公网隧道(无需注册账号)
3. 窗口中会打印公网地址,形如 `https://XXX.trycloudflare.com`

**把公网地址发给朋友,任何网络都能打开直接联机**(手机流量也行)。

> ⚠️ 注意:
> - 保持「联机上网.bat」窗口开着,隧道才有效;关窗即断开公网。
> - 每次运行会生成**新的公网地址**(免费隧道地址不固定),需要把新地址重新发给朋友。
> - 免费隧道为临时服务,适合朋友联机;如有长期稳定需求可注册 Cloudflare 账户改用固定域名。

## 玩法概要(详见《我的卡牌》规则文档)

- **目标**:摧毁对方本体建筑(主城)即获胜
- **牌堆**:无限,按文档权重加权随机抽牌;无权重卡(本体/城墙/外城)开局直接上场、不会被抽到;标数量的卡限制场上最多数量
- **回合**:随机先后手 → 体力刷新 → 每方固定抽 3 张 → 出牌 → 状态结算
- **体力**:每阵营每回合固定 3 点,打牌消耗体力
- **出牌流程**:点手牌放入「待出牌区」→ 指定目标(如需要)→ 点「确定出牌」才生效;体力不足会提示
- **选定攻击目标**:伤害牌可点击对方建筑指定目标;场上出现更高「优先受伤」建筑时自动锁定且不可降级,同级可自由选择
- **明牌对战**:双方手牌对彼此可见,可针对性破招/拟态
- **状态效果**:独立状态栏显示效果与等级(辐射 / 火 / 电 / 冰 / 毒 / 虚弱 / 凋零 / 乱码),长按卡牌可查看完整效果
- **减伤卡(设防/额外城防/电网/穹顶/虚空盾)**:打出当回合不生效,**轮到对方回合时提供一回合减伤**(打出后状态栏显示「减伤待发 · 对方回合生效一回合」),对方回合结束后清除
- **1v1v1 三方混战**:三人各执一个独立阵营,回合 1→2→3 轮转;一方主城被摧毁即淘汰,对局继续,直到**最后存活一方获胜**;断线由 AI 托管

## 五阵营

| 阵营 | 本体 | 特点 |
|---|---|---|
| 主世界 | 虚空国主城 1000血 | 均衡,修复+核打击 |
| 地狱 | 地狱堡垒 1200血 | 免疫火,高血,火/凋零压制 |
| 终界 | 终界城 1000血 | 护盾保本体,吸血+安息 |
| 虫族 | 母体 800血 | 建筑增益叠加,增生强化 |
| 创世神 | MINECRAFT 500→1000 | 二阶段,免疫状态,乱码+湮灭 |

## 2v2 说明(四人独立)

- 每队 2 人,**四人各执一个独立阵营**,属性 / 状态效果 / 体力 / 手牌 / 建筑完全独立
- 回合交替顺序:队0甲 → 队1甲 → 队0乙 → 队1乙(1-2-3-4 轮转)
- 伤害牌可点击敌方区块切换**攻击目标**;攻击所有建筑的卡(电磁炮/轰炸等)会波及对方两人
- 队友之间用右侧「聊天」交流

## 1v1v1 说明(三方混战)

- 三人各执一个独立阵营(属性/状态/体力/手牌完全独立),创建房间选「1v1v1」+ 电脑对手即可一人开三方
- 回合轮转:0 → 1 → 2 → 0;顶栏显示具体谁的回合
- **淘汰制**:一方本体被摧毁即淘汰(跳过其回合),剩余两方继续互打,最后存活一方获胜
- 伤害牌可点击敌方区块切换攻击目标(其余两家都是敌人)

## 🤖 电脑 AI(三种难度)

**创建房间时可选电脑补齐人数**,一个人也能玩:

| 难度 | 行为 |
|---|---|
| 简单 | 随机出牌,常提前结束回合 |
| 普通 | 按局面评估,低价值牌有时不出 |
| 困难 | 只出正收益牌,集火残血本体 |

- **1v1 人机练习**:创建房间选「电脑对手」难度 → 直接开始,AI 自动行动
- **2v2 人机混编**:创建房间选「电脑队友 / 电脑对手」→ 一人可打 2v2,两人也能各自带 AI 打 2v2
- **1v1v1 人机混战**:创建房间选「1v1v1」+ 电脑对手难度 → 一人可打三方混战,两个 AI 自动行动
- **真人顶替**:AI 只是占位,真人随时加入会自动顶替掉队伍里的 AI
- **接管队伍**:真人全部退出后,该队由 AI 自动托管继续打完(纯 AI 也能自动对局)
- 房间列表带 🤖 标记的即含电脑

## 项目结构

```
卡牌对决/
├── start.bat            # 一键启动(自动打开浏览器)
├── server/
│   ├── server.js        # 服务器(WebSocket+房间+静态服务)
│   ├── game-engine.js   # 规则引擎(服务器权威,防作弊)
│   └── ai.js            # 电脑 AI 决策(简单/普通/困难)
├── public/
│   ├── index.html       # 单页应用:大厅 + 对战(同页切换)
│   ├── css/style.css
│   ├── js/              # 卡牌数据 / 网络 / 大厅 / 对战逻辑
│   └── assets/          # 你的阵营素材(卡牌图/卡背)
└── test-*.js            # 自动化测试(含 test-ai.js / test-ai-unit.js)
```
